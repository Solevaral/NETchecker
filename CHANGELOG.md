# История изменений

Версии нумеруются по образцу [семантического версионирования](https://semver.org/lang/ru/):
`МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ`.

Пока мажорная версия равна нулю, программа считается складывающейся: формат файла настроек
и состав проверок ещё могут меняться. Начиная с `1.0.0` ломающие изменения будут повышать
мажорную версию.

Метка в репозитории совпадает с версией в `Cargo.toml` и выглядит как `v0.1.0`.

## v0.1.0 — 6 августа 2026

Первый выпуск. Программа отвечает на вопрос «почему не работает интернет»: показывает цепочку
от компьютера до сайта, отмечает участок, где теряется связь, и объясняет причину дважды —
простыми словами и на языке сетевика.

### Диагностика по уровням OSI

- Сетевые адаптеры, состояние линка, IP-адрес, распознавание APIPA, шлюз по умолчанию.
- Точный ICMP: на Windows через `IcmpSendEcho` — **без прав администратора**, на Unix через
  ICMP-сокеты. Задержки, потери и разброс по четырём пробам.
- Трассировка маршрута с разбором участков: ваша сеть, ещё один роутер в цепочке, CGNAT,
  провайдер. Второй роутер в квартире не выдаётся за провайдера.
- Доступность опорных узлов интернета, поиск административных запретов на пути.

### Разбор блокировок

- Сравнение системного DNS с эталонным ответом по HTTPS: подмена адреса, ответ «сайта
  не существует» там, где он есть.
- Обнаружение перехвата провайдером запросов к чужим DNS-серверам.
- Фильтрация по имени сайта: три пробы на один адрес — с настоящим именем, с нейтральным
  и с разделённым первым пакетом.
- Признаки транзитного фильтра: обрыв быстрее физически возможного, одинаковое поведение
  у несвязанных сайтов, влияние разделения пакета.
- Страницы-заглушки провайдеров и подмена сертификата.
- Замер скорости и поиск избирательного замедления с поправкой на расстояние.

### Окно

- Схема сети с адресами узлов и отметкой места обрыва.
- Разбор по уровням L1–L7 с переключателем «простой / экспертный режим».
- Свой список целей: домены и IP построчно, с разбором ошибок ввода.
- Наблюдение за связью: график задержек и журнал обрывов.
- Отчёт для отправки в поддержку — копированием или файлом.
- Значок рядом с часами: цвет по состоянию связи, закрытие окна прячет программу туда.
- Автозапуск вместе с системой.

### Честность выводов

- При работающем средстве обхода DPI программа не утверждает, что блокировок нет: обход
  для того и запущен, чтобы фильтр не сработал.
- Прерванная проверка не выдаёт вердикт — вывод по половине данных хуже отсутствия вывода.
- Когда разницу в скорости объясняет расстояние, программа говорит это прямо, а не выдаёт
  географию за замедление.

### Известные ограничения

- Системных уведомлений об обрыве нет: программа сообщает о нём цветом значка и подсказкой.
- Сборка и проверка велись на Windows. Код кроссплатформенный, но на Linux не обкатан.
- Подпись сертификата удостоверяющим центром не проверяется — сверяется только имя.
